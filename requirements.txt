callback.py

py -m src.training.callbacks --config configs/cnn_baseline.yaml

callbacks.py không train model trực tiếp. Nó chứa các “hành động phụ” được Keras gọi trong quá trình train.

Khi chạy model.fit(), callbacks sẽ tự động làm các việc như:

Sau mỗi epoch:
→ kiểm tra val_roc_auc
→ nếu model tốt hơn thì lưu checkpoint
→ nếu model không cải thiện nhiều epoch thì dừng sớm
→ nếu val_loss không giảm thì giảm learning rate
→ ghi log train vào file CSV

==========================================================================================================================

train_cnn.py là file huấn luyện mô hình CNN baseline.

Các file trước đó chỉ chuẩn bị từng phần:

make_metadata.py      → tạo train.csv/dev.csv/eval.csv
logmel.py             → tạo feature .npy
dataset_loader.py     → load .npy thành tf.data.Dataset
cnn_baseline.py       → định nghĩa kiến trúc CNN
callbacks.py          → tạo checkpoint, early stopping, logger
train_cnn.py          → ghép tất cả lại và train model

==> train_cnn.py = file chính để bắt đầu huấn luyện CNN baseline.

Sau khi chạy train_cnn.py, project mới sinh ra model thật trong:

outputs/checkpoints/cnn_baseline/best_cnn_baseline.keras
outputs/saved_models/cnn_baseline/cnn_baseline_final.keras
outputs/logs/cnn_baseline/training_log.csv


Cú pháp train:

py -m src.training.train_cnn --config configs/cnn_baseline.yaml

evaluate\metrics.py: File này dùng để tính các chỉ số đánh giá mô hình sau khi model đã predict xong.

Cụ thể, sau này evaluate.py sẽ làm:

Load model
→ Load dev/eval dataset
→ model.predict()
→ thu được y_true và y_score
→ gọi metrics.py để tính kết quả

metrics.py sẽ tính:

Accuracy
Precision
Recall
F1-score
ROC-AUC
EER
Confusion Matrix
Classification Report
Best threshold theo F1
Best threshold theo Youden's J

Nói ngắn gọn:

metrics.py = nơi tính toán chỉ số đánh giá mô hình
evaluate.py = nơi load model, predict, gọi metrics.py và lưu kết quả

py -m src.evaluation.metrics

3. Evaluate full eval để làm gì?

python -m src.evaluation.evaluate --config configs/mobilenetv3_small.yaml --split dev --threshold 0.864 --output-dir outputs/results/mobilenetv3_small/evaluate_dev_finetuned_thr_0864

Sau khi chọn threshold từ dev, bạn dùng threshold đó để evaluate trên eval.

Quy trình chuẩn là:

Train trên train
Theo dõi/chọn model bằng dev
Chọn threshold bằng dev
Đánh giá cuối cùng trên eval

Train xong → model có trọng số mới
Evaluate full dev → biết model mới tốt đến đâu và chọn threshold
Evaluate full eval → lấy kết quả cuối cùng để báo cáo

Ví dụ CNN của bạn:

Dev chọn threshold = 0.956
Eval chạy với threshold = 0.956

Khi đó kết quả eval mới có giá trị báo cáo cuối.
